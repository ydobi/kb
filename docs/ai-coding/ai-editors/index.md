# AI 编辑器/IDE

AI 增强的编辑器和 IDE 使用指南。

## 工具列表

| 工具 | 特点 | 适用场景 |
|------|------|----------|
| [Cursor](/ai-coding/ai-editors/cursor) | IDE 深度集成，多模型支持 | 全栈开发、重构 |
| [Copilot](/ai-coding/ai-editors/copilot) | GitHub 生态，主流 IDE 支持 | 代码补全、单元测试 |
| [Claude Code](/ai-coding/ai-editors/claude-code) | CLI 工具，强大推理能力 | 复杂任务、代码分析 |

## 选择建议

- **新手入门**: Copilot - 安装简单，学习曲线平缓
- **深度用户**: Cursor - 功能丰富，可定制性强
- **终端爱好者**: Claude Code - CLI 体验，适合复杂任务
