## 日常工作流

### 1. 代码编写

```
需求分析 → AI 生成初版 → 人工审查 → 迭代优化
```

### 2. 代码审查

```
提交代码 → AI Review → 修复问题 → 再次审查
```

### 3. 文档编写

```
代码完成 → AI 生成文档 → 人工校对 → 发布
```

## 效率提升技巧

### 快捷键优先

熟练使用 AI 工具的快捷键，减少鼠标操作。

### 上下文管理

- 打开相关文件
- 使用 @ 符号引入上下文
- 保持对话简洁

### 模板复用

创建常用 Prompt 模板，避免重复输入。

## 工作流示例

### 新功能开发

1. **需求理解**: 让 AI 帮你分析需求文档
2. **方案设计**: 与 AI 讨论技术方案
3. **代码实现**: AI 生成代码，人工审查
4. **测试编写**: AI 生成测试用例
5. **文档更新**: AI 更新相关文档

### Bug 修复

1. **问题分析**: AI 分析错误信息和代码
2. **定位问题**: AI 帮助定位问题根源
3. **修复验证**: AI 生成修复方案，人工验证
4. **回归测试**: AI 生成回归测试用例
