# AI Coding

AI 辅助编程工具的使用技巧与最佳实践。

## 工具概览

| 工具 | 特点 | 适用场景 |
|------|------|----------|
| Cursor | IDE 深度集成，多模型支持 | 全栈开发、重构 |
| Copilot | GitHub 生态，主流 IDE 支持 | 代码补全、单元测试 |
| Claude Code | CLI 工具，强大推理能力 | 复杂任务、代码分析 |

## 核心技能

1. **Prompt 编写** - 如何编写有效的 AI Prompt
2. **上下文管理** - 合理组织代码上下文
3. **代码审查** - 利用 AI 进行代码 Review
4. **重构辅助** - AI 辅助代码重构技巧
