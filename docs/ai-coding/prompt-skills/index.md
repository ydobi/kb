# Prompt 技巧

编写有效的 AI Prompt，提升 AI 编程效率。

## 核心原则

### 1. 清晰具体

```markdown
# 好的 Prompt
将 getUserData 函数重构为使用 async/await，
添加错误处理，返回类型改为 Result<User, Error>

# 不好的 Prompt
改一下这个函数
```

### 2. 提供上下文

```markdown
# 好的 Prompt
项目使用 React + TypeScript + Zustand。
请创建一个用户列表组件，支持分页和搜索。

# 不好的 Prompt
创建一个用户列表组件
```

### 3. 分步骤处理

将复杂任务拆分为小步骤：
1. 先分析需求
2. 设计数据结构
3. 实现核心逻辑
4. 添加错误处理
5. 编写测试

## 常用模式

### 代码生成

```
创建一个 [组件名] 组件：
- 使用 [技术栈]
- 接收 [props] 参数
- 功能：[详细描述]
- 样式：[样式要求]
```

### 代码重构

```
重构 [文件/函数名]：
- 目标：[重构目标]
- 保持：[需要保留的行为]
- 注意：[约束条件]
```

### Bug 修复

```
分析这段代码的问题：
[代码片段]

错误信息：[错误信息]
预期行为：[预期行为]
```

## 高级技巧

### 角色设定

```
你是一个资深前端工程师，擅长 React 性能优化。
请帮我分析这个组件的性能问题...
```

### 示例驱动

```
参考这个实现：
[示例代码]

请用类似的模式实现 [新功能]
```
