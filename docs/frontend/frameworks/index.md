# 框架

前端框架使用指南和最佳实践。

## 文档

| 框架 | 说明 |
|------|------|
| [React](/frontend/frameworks/react) | 声明式 UI 库 |
| [Vue](/frontend/frameworks/vue) | 渐进式框架 |

## 框架对比

| 特性 | React | Vue | Angular |
|------|-------|-----|---------|
| 学习曲线 | 中等 | 平缓 | 较陡 |
| 灵活度 | 高 | 中 | 低 |
| 生态规模 | 最大 | 大 | 大 |
| TS 支持 | 好 | 好 | 原生 |

## 选择建议

- **React**: 大型应用、团队熟悉函数式编程
- **Vue**: 快速上手、模板语法偏好
- **Angular**: 企业级应用、完整解决方案
